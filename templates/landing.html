events · nearby · now

Find events, wherever you are.

terminschleuder is a geospatial events discovery platform. A read-only REST API surfaces events near a city or coordinates, backed by a 2000+ city gazetteer, an ingestion pipeline with full provenance, and multi-tenant organization ownership.

Try the demo → Explore the API

Everything an unauthenticated client can do

A public, read-only surface — designed to be embedded in any customer site.

📍

Proximity search

Find events near a city (gazetteer centroid) or near arbitrary lat/lon, with a configurable radius. Online events are excluded from proximity results and distance is annotated on every hit.

🗺️

City gazetteer

A 2000+ European city catalog (PostGIS) with slugs, coordinates, and per-city default radii — the backbone of the near_city filter and the map views.

🔗

Ingestion & provenance

An extractor surface pulls from approved sources into an observation queue; operators review and promote observations to canonical events. Every event carries its original URL, platform, source, and promotion provenance.

🏢

Multi-tenant ownership

Organizations own their events and sources through group-based permissions. Service accounts and API keys scope extractor access per organization.

🛡️

Read-only public API

Anonymous clients get safe, read-only GET access to events, cities, venues, organizations, and categories — CORS-enabled and self-describing via OpenAPI 3.

🖥️

Reference demo client

A React + TypeScript SPA demonstrates the full customer experience: filters, proximity, maps, pagination, and live API configuration — one image, any backend.
